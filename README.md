# Banking System (C++)
A beginner-friendly console-based Banking System developed using C++. It allows users to check their account balance, deposit money, and withdraw money through a simple menu-driven interface.

# Features
Display current bank balance
<br>
Deposit money
<br>
Withdraw money
<br>
Check for insufficient balance
<br>
Basic input validation
<br>
Menu-driven interface

# Concepts Used
Functions and return values
<br>
Do-while loop
<br>
Switch statements
<br>
Conditional statements
<br>
Input validation
<br>
C++ I/O manipulation using iomanip

# Language
C++
